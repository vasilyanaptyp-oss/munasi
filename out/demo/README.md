# Демонстрация

`ten-abilities.mp4` — один бой, в котором по очереди срабатывают все десять
новых способностей. Кулдауны разведены так, чтобы каждая была отдельным
моментом, HP задраны, чтобы бой не кончился раньше времени. Это **не** образец
формата: длина, числа и баланс здесь ничего не значат, смотреть надо на
механику.

| время | способность | что видно |
| --- | --- | --- |
| 3.0с | `switcheroo` | двое меняются концами арены в одном кадре |
| 5.6с | `magnet_pull` | полёт противника загибается внутрь |
| 8.2с | `spin_cycle` | одна фотография кружит вокруг другой |
| 10.8с | `overclock` | фигура заметно ускоряется, каждый контакт — крит |
| 13.4с | `dead_weight` | встал намертво и побледнел, второй отскакивает |
| 16.0с | `wall_slam` | кастер уходит в стену, жертву швыряет от неё |
| 18.6с | `siphon` | жёлто-зелёное число уходит, зелёное приходит |
| 21.2с | `countdown` | ничего, а через 2.5 секунды вспышка на другом конце |
| 23.8с | `riposte` | каждый удар по нему появляется дважды |
| 26.4с | `slipstream` | полупрозрачный, проходит сквозь противника |

Персонажи здесь — существующие фотографии: способности навешены поверх, потому
что своих фотографий у новых персонажей ещё нет.
