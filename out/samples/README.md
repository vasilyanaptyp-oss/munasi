**Сиды другие, и по-другому быть не могло.** Симуляция изменилась: у бойцов
появились позиции, а частота атак выросла втрое. Тот же номер сида теперь даёт
другой бой, так что отбор лучшего из 400 сидов выбрал другие. Матчапы те же.

- «движение» — доля пикселей, меняющихся за кадр, замеряется на готовом mp4
  (`pnpm motion`). Порог 8%, референс 12.7%, прошлая версия 3.0-4.9%.
- «макс. пауза» — самый длинный промежуток без событий. Порог 1.2с.

## Что изменилось

- **У бойцов есть позиции.** Сближаются, бьют, отходят, смещаются вбок. Всё в
  симуляции, на своих потоках seeded RNG.
- **Втрое чаще и втрое слабее удары.** DPS не изменился по построению.
- **Камера следит** за схваткой с запаздыванием и подстраивает зум под разлёт.
- **У пола арены появилась разметка**, которая едет вместе с камерой. Без неё
  пан не виден вообще: поле внутри арены одноцветное, а сама арена прибита.

## Как они сняты

```
pnpm generate --count 2 --pick=0,33  --no-cold-open --out=out/samples --seeds 400
pnpm generate --count 2 --pick=66,99                --out=out/samples --seeds 400
pnpm motion out/samples/*.mp4
```
