# Образцы

`compass-vs-bodyguard-168.mp4` — первый ролик нового формата.

| | значение |
| --- | --- |
| матчап | COMPASS GUY vs BODYGUARD GUY |
| seed | 168 |
| длина | 30.7с |
| движение (тело) | **11.7%** изменившихся пикселей за кадр, 0% статичных |
| статики в файле | 33 кадра из 60 разрешённых |
| холодное открытие | да |

Референс меряется на 12.7%. Порог гейта — 8%.

## Что в нём есть

- вырезанные фотографии с белой обводкой на плоском синем поле;
- **отскок от стен**: каждый летит по прямой и отражается, за ролик они успевают
  поменяться сторонами;
- **камера едет**: арена вместе с рамкой панорамируется, меняет масштаб и
  срезается краем кадра;
- HP-крест над головой своего бойца, едет вместе с ним;
- заголовок двумя строками, «Like and Subscribe!» снизу;
- **MAGNETIC NORTH** — компасная роза во всю арену, стрелка втыкается в сторону,
  и противнику переписывается направление;
- **NOBODY MOVES** — вспышка на весь кадр, противник стоит 1.4 секунды.

## Чего ещё нет

Ростер — два человека, поэтому матчап один. Добавляется третий и дальше через
`assets/fighters/source/` + `pnpm cutout` + запись в `roster.ts`; каждому нужна
своя способность во весь экран, иначе смотреть нечего.

## Как снят

```
pnpm generate --count 1 --out=out/samples --seeds 300
pnpm motion out/samples/*.mp4
```
