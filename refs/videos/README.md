# Видео-референсы

Сюда кладутся сами ролики референсного канала, чтобы `pnpm compare` было с чем
сравнивать:

```
pnpm compare out/samples/*.mp4 -- refs/videos/*.mp4
```

**Они не в гите, и это намеренно.** Это чужие ролики: они годятся для того,
чтобы мерить по ним свой формат, но раскладывать их копии в репозитории —
другое действие. Скриншоты для разбора в `refs/` лежат, а видео кладутся руками,
как и всё остальное в `assets/`.

Что мерится по ним — в `src/export/measure.ts`. Инструмент ничего не скачивает.
