# munasi — правила проекта

Генератор коротких вертикальных видео с боями персонажей (TikTok/Shorts, 1080x1920, 30fps).

## Архитектурные правила (не нарушать)

1. **`src/sim/` ничего не знает о рендере.** Только чистые функции и типы данных.
   Ноль импортов из `src/render/`, `src/export/`, ноль обращений к fs, canvas, ffmpeg.
2. **Вся случайность идёт через seeded RNG** (`src/sim/rng.ts`, mulberry32).
   `Math.random` запрещён во всём `src/`. Есть тест, который это проверяет.
3. **Одинаковый seed = побайтово одинаковое видео.** Никаких зависимостей от
   `Date.now()`, порядка обхода Map/Set с непредсказуемыми ключами, плавающих
   таймингов. Симуляция целиком детерминирована; рендер — чистая функция от снапшота.
4. **Каждый модуль покрыт тестами до того, как двигаемся дальше.**

## Технические решения

- Тик симуляции: **60/сек**. Видео: **30 fps**. Снапшот пишется каждый второй тик,
  ровно по одному на кадр видео.
- События (`MatchEvent`) несут номер **кадра видео**, не тика — рендер и звук
  работают в кадрах.
- Таймаут боя: 60 секунд (3600 тиков / 1800 кадров).
- Числа с плавающей точкой в симуляции: копятся только в аккумуляторах
  (`attackCooldown`, `hp`). Все сравнения — через `<= 0`, без epsilon-трюков.
- Формат `MatchResult` сериализуется в JSON без потерь — на этом построен тест
  детерминизма.
- Спрайты процедурные (`src/render/sprites.ts`): рисуются кодом из палитры бойца,
  никаких сторонних изображений и реальных людей.

## Стек

TypeScript strict + Node 20+ + pnpm, vitest, `@napi-rs/canvas` для кадров,
ffmpeg через `child_process` для сборки. Внешних зависимостей минимум.

## Структура

```
src/sim/      — чистая симуляция боя (rng, types, simulate, drama)
src/render/   — отрисовка кадров в PNG
src/export/   — сборка видео через ffmpeg
src/content/  — JSON-конфиги персонажей, баланс, матчапы
src/cli/      — точки входа
assets/       — спрайты, звуки
out/          — готовые видео (в .gitignore)
```

## Команды

```
pnpm test        # vitest
pnpm typecheck   # tsc --noEmit
pnpm balance     # матрица винрейтов по всем парам
pnpm frame       # отрендерить один тестовый кадр
pnpm generate --count 20
```
